# 手搖珍奶職人模擬器 (Boba Master Simulator v2.0) 🧋✨

「手搖珍奶職人模擬器」是一款專為 VS Code 與 GitHub Pages 所設計的純前端互動網頁遊戲。玩家將扮演手搖飲店長，在限時內根據隨機上門客人的訂單需求，準確調配出符合茶底、配料、冰塊與甜度的完美手搖飲，挑戰賺取最高營業額與顧客評價！

線上遊玩連結：[手搖珍奶職人模擬器](https://jasminechuang.github.io/bubbletea_game/)

---

## 🌟 遊戲特色

- **豐富的客群與隨機訂單**：涵蓋多種角色（如上班族、大學生、工程師等）與動態生成的訂單需求（包含茶底、配料、冰塊、甜度）。
- **即時視覺化工作台**：製作飲品時，杯身液體高度、顏色及沉澱配料（珍珠、椰果、布丁）會即時呈現。
- **智慧評分系統**：依據茶底、配料、冰塊及甜度的準確度進行智慧扣分與結算，並即時更新營業額與綜合星級評價。
- **純前端實作**：無需複雜的後端伺服器，單一檔案即可順暢運行。

---

## 🛠️ 技術堆疊 (Tech Stack)

- **HTML5 / CSS3**：結構與介面排版
- **Tailwind CSS (CDN)**：快速構建現代化且響應式的 UI 介面
- **JavaScript (ES6+)**：遊戲核心邏輯、動態 DOM 操作與狀態管理
- **Google Fonts (Noto Sans TC)**：提供優美且清晰的繁體中文字型支援

## 🚀 快速開始與本地執行

因為本專案為純前端網頁（Pure Frontend Web App），你可以直接透過以下方式在本地端執行：

1. **複製專案庫 (Clone Repository)**
   ```bash
   git clone [https://github.com/jasminechuang/bubbletea_game.git](https://github.com/jasminechuang/bubbletea_game.git)
   ```
2. **開啟檔案**
直接在你的瀏覽器中雙擊打開 index.html 檔案，或是透過 VS Code 的 Live Server 擴充功能進行預覽。

## 🎯 遊戲玩法說明
點擊 「🔔 迎接下一位客人」按鈕，查看客人的點單需求明細（例如：紅茶、加珍珠、少冰、微糖）。

在 「原料控制台」 依序選擇對應的茶底、添加配料，並調整冰塊與甜度選單。

確認工作台預覽無誤後，點擊 「✨ 出餐給客人！」 即可獲得評分與獎金。
